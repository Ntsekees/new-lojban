This repository is about a project of a variant of the Lojban language (an engineered constructed language), variant currently called “New Lojban”, “Ninjbobau”, or “Nijbo”.

For now, this repository only contains the lexicon of the language. You can browse it [there](<https://ntsekees.github.io/new-lojban/lexicon/browser/index.html>), on the GitHub Pages for this repository.

The lexical data is in the `lexicon/lexicon.json` file.

It is possible to submit proposals of new lexical items using [this Google Form](<https://docs.google.com/forms/d/e/1FAIpQLSc-dGZejymMmuvNi5fhs8oU7b5wDxWHHfDQ87deyxkU2O9AgA/viewform>), whose content can be automatically added to the lexicon JSON using the `lexicon/tools/fetch-lexical-submissions.py` script.
